Embed with an iframe

Three ways to show the same tag #100. Each frame owns its drawing and, when needed, its controls. This host loads only shared demo theming and a same-origin frame sizing script, not the player modules or controls stylesheet.

Full player with controls

Play, pause, scrub and change the ink. This example includes the optional controls and a remove button that releases the player.

Open the player on its own

<iframe class="player-frame" src="./player.html"
  title="Graffiti player"
  loading="lazy"
  style="width:100%;height:800px;border:0">
</iframe>

This minimal embed uses a fixed height and scrolls if its content needs more room. The gallery instead fits the frame to its content, including after you remove the player.

Animation only

The drawing fills its frame and loops without controls. No UI module or stylesheet is loaded. With reduced motion enabled, it shows the finished tag instead.

Open the animation on its own

<iframe src="./playback.html"
  title="Animated graffiti drawing"
  loading="lazy"
  style="width:100%;aspect-ratio:1;border:0">
</iframe>

Finished drawing

One frame, painted once. This example uses parse, prepare and paint: no player, animation loop or controls.

<iframe class="drawing-frame" src="./draw.html"

The gallery fits this frame to the drawing and its wrapped text. The fixed height above is a standalone starting point.

Put a frame on another site

Each example uses bundled JSON. Its JSON and module URLs resolve relative to the framed page, not the host page.

  • Replace src with the absolute HTTPS URL of your hosted example. Serve the modules and tag.json alongside it over HTTP or HTTPS, not file://.
  • Set the frame size on the host page. The minimal examples above use a fixed height for text and controls; check your chosen height at narrow widths and keep scrolling available. Animation-only frames stay square.
  • This gallery uses ResizeObserver on each same-origin player and drawing page's body. Their content determines the frame height, so wrapped controls fit and removing the player shrinks its frame. Place the sizing script below after the matching iframes on the same origin; it cannot measure cross-origin content.
  • The gallery, player and drawing share the demo theme through same-origin storage. They follow the system until you choose a theme. The animation-only frame stays black and loads no UI or theme files.
  • The host's frame-src policy must allow the player URL. The player's frame-ancestors and X-Frame-Options headers must allow the host.
  • If you add a sandbox, module loading and playback need allow-scripts allow-same-origin. Use those permissions only for content you trust.
  • The host cannot control a cross-origin player through these examples. There is no postMessage API.

You can also embed the full demo with ../?renderer=canvas&id=147&fullscreen=1 as the source. That version loads its tag from 000000book rather than the bundled JSON.

<script>
document.querySelectorAll('.player-frame, .drawing-frame').forEach(frame => {
  let observer;
  frame.addEventListener('load', () => {
    if (observer) observer.disconnect();
    const body = frame.contentDocument?.body;
    if (!body) return;
    observer = new ResizeObserver(() => {
      const style = getComputedStyle(frame);
      const border = parseFloat(style.borderTopWidth) + parseFloat(style.borderBottomWidth);
      frame.style.height = Math.ceil(body.getBoundingClientRect().height + border) + 'px';
    });
    observer.observe(body);
  });
});
</script>
